Read every document in a folder, in one window.

Folium is a fast, read-only viewer for Word, Excel, CSV, PDF, e-books, Markdown and more. Point it at a folder and click through everything in seconds. It never changes your files and never uploads them.

Download for Mac Linux & other installs
brew install --cask mveselovski/tap/folium

Free and open source · macOS (Apple silicon & Intel) and Linux · signed and notarized by Apple

One viewer for a mixed folder

Many formats

Word, Excel, OpenDocument, CSV/TSV, PDF, EPUB and FB2 e-books, Markdown, HTML and plain text.

Text in any language

Detects UTF-8, UTF-16 and legacy encodings such as Windows-1251 (Cyrillic) and Windows-1252.

E-books

EPUB chapter by chapter and FictionBook with a contents menu. Folium remembers where you stopped reading each book.

Spreadsheet tabs

Multi-sheet .xlsx, .xls and .ods files get a tab per sheet.

Safe HTML preview

HTML files open in a sandboxed frame.

Folder tree & themes

Sort by name, type or date. Light and dark themes, remembered between sessions.

Supported formats

FormatExtensions
Word.docx, .doc (formatted on macOS, plain text on Linux)
Excel.xlsx, .xls
OpenDocument spreadsheet.ods
CSV / TSV.csv, .tsv
PDF.pdf
EPUB.epub
FictionBook.fb2, .fbz, .fb2.zip
Markdown.md
HTML.html, .htm
Plain text.txt

Private by design

  • Read-only. Folium never creates, changes or deletes anything.
  • Local. Documents are converted on your machine. Nothing about your files is sent anywhere.
  • Yours only. It's a small local server that only your computer can reach, shown in its own Mac app window or in your browser.

Get Folium

macOS app

Download the .dmg or run brew install --cask mveselovski/tap/folium.

Command line

brew install mveselovski/tap/folium, then folium ~/Documents.

Linux

One self-contained binary for x64 and arm64. Install instructions.
